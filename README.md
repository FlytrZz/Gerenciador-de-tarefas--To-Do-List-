# Gerenciador de Tarefas (To Do List)

Desenvolvimento de sistema desktop To-Do List em Java utilizando Swing, JTable, POO, CRUD, Gson e persistência de dados em JSON.

## 🧠 Conhecimentos utilizados
- Java
- POO
- Listas e Coleções
- Tratamento de Erros
- Interface Gráfica
- Gson e Conversão para JSON

## 📋 Funcionalidades
- Adiciona tarefas
- Mostra tarefas em tabela
- Edita tarefas
- Remove tarefas
- Filtra tarefas
- Salva os dados em JSON
- Carrega dados novamente

## ▶️ Como executar
1. Clone o repositório
2. Abra no Eclipse
3. Execute a classe Main
